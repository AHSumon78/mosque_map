# 🕌 Bangladesh Mosque Map & Admin Portal (বাংলাদেশ মসজিদ ম্যাপ ও এডমিন পোর্টাল)

সম্পূর্ণ বাংলাদেশ জুড়ে মসজিদের ভৌগোলিক অবস্থান (নাম, অক্ষাংশ, দ্রাঘিমাংশ) সংরক্ষণ, মহিলাদের জন্য আলাদা নামাজের ব্যবস্থা (`has_female_facility`) ট্র্যাকিং ও আপডেট, ম্যাপে প্রদর্শন, ব্যবহারকারীর নিকটবর্তী মসজিদ অনুসন্ধান, মাল্টি-এডমিন একাউন্ট ম্যানেজমেন্ট এবং সিএসভি (CSV) ডাটা সরাসরি ইমপোর্ট করার ফুল-স্ট্যাক ওয়েব অ্যাপ্লিকেশন ও REST API।

---

## ✨ প্রধান বৈশিষ্ঠ্যসমূহ (Key Features)

1. **👥 মাল্টি-ইউজার ও এডমিন একাউন্ট ম্যানেজমেন্ট (Account Management):**
   - **পাসওয়ার্ড পরিবর্তন:** বর্তমান পাসওয়ার্ড যাচাই করে নতুন পাসওয়ার্ড সেট করার সুবিধা।
   - **নতুন একাউন্ট তৈরি:** নতুন এডমিন বা এডিটর একাউন্ট তৈরি করার সরাসরি UI সুবিধা।
   - **ইউজার তালিকা ও ডিলিট:** বিদ্যমান সকল একাউন্ট দেখা এবং অপ্রয়োজনীয় একাউন্ট ডিলিট করার ব্যবস্থা।
   - **নিরাপত্তা:** পাসওয়ার্ড ক্রিপ্টোগ্রাফিক সল্ট ও হ্যাশ (`PBKDF2-SHA512`) দিয়ে ডাটাবেসে সুরক্ষিত।
2. **ইন্টারেক্টিভ লিফলেট ম্যাপ (Leaflet.js + MarkerCluster):**
   - ৫০,০০০+ মসজিদ থাকলেও ম্যাপ কখনো হ্যাং বা ল্যাগ করবে না (স্মার্ট মার্কার ক্লাস্টারিং)।
   - **স্বয়ংক্রিয় ডাটা লোড:** ম্যাপ ওপেন করলেই বা ড্র্যাগ/প্যান করলেই ভিউপোর্টের মসজিদগুলো লাইভ চলে আসবে।
   - যেকোনো স্থানে ক্লিক করলেই নির্দিষ্ট ব্যাসার্ধের (Radius) ভিতরের সকল মসজিদ ফিল্টার হয়ে যাবে।
3. **লাইভ সার্চ ও নিকটবর্তী মসজিদ অনুসন্ধান:**
   - মসজিদের নাম টাইপ করার সাথে সাথে লাইভ সার্চ এবং কার্ডে ক্লিক করলে সরাসরি ম্যাপে ফোকাস।
   - ব্যবহারকারীর মোবাইল/ল্যাপটপের বর্তমান জিপিএস অবস্থান থেকে ১-২০ কিমি পরিধির মসজিদ খোঁজা।
4. **🧕 মহিলাদের নামাজের ব্যবস্থা (Female Prayer Space Facility):**
   - ডাটাবেস কলাম: `has_female_facility BOOLEAN DEFAULT FALSE`।
   - ফ্রন্টএন্ডে **ফিল্টার টগল:** শুধুমাত্র মহিলাদের ব্যবস্থা আছে এমন মসজিদ আলাদাভাবে দেখার সুবিধা।
   - **আপডেট করার API:** ওয়েবসাইট থেকেই যেকোনো মসজিদের মহিলাদের ব্যবস্থা সরাসরি আপডেট (`PATCH /api/v1/mosques/:id`) করার সুবিধা।
5. **সরাসরি CSV ফাইল ইমপোর্ট (Web UI & CLI Importer):**
   - ব্রাউজার থেকে ড্র্যাগ & ড্রপ করে ১০০MB পর্যন্ত যেকোনো সাইজের CSV ফাইল সরাসরি ইমপোর্ট করার সুবিধা।
   - **ডুপ্লিকেট সুরক্ষা:** কোঅর্ডিনেটসের ওপর `UNIQUE KEY uk_coords (latitude, longitude)` থাকায় কোনো মসজিদ দুইবার ঢুকবে না (`ON DUPLICATE KEY UPDATE`)।

## 📡 REST API ডকুমেন্টেশন

| Method | Endpoint | Description | Auth Required |
|---|---|---|---|
| `POST` | `/api/v1/auth/login` | ইউজারনেম ও পাসওয়ার্ড দিয়ে লগইন | No |
| `GET` | `/api/v1/auth/verify` | সেশন যাচাই | Yes (Bearer Token) |
| `POST` | `/api/v1/auth/logout` | সেশন লগআউট | Yes |
| `POST` | `/api/v1/auth/change-password` | বর্তমান পাসওয়ার্ড পরিবর্তন | **Yes** |
| `GET` | `/api/v1/auth/users` | সমস্ত এডমিন/ইউজার একাউন্টের তালিকা | **Yes** |
| `POST` | `/api/v1/auth/users` | নতুন এডমিন/ইউজার একাউন্ট তৈরি | **Yes** |
| `DELETE`| `/api/v1/auth/users/:id` | নির্দিষ্ট ইউজার একাউন্ট ডিলিট | **Yes** |
| `GET` | `/api/v1/mosques/nearby` | নিকটবর্তী মসজিদসমূহ | No |
| `GET` | `/api/v1/mosques/search` | নাম অনুযায়ী মসজিদ অনুসন্ধান | No |
| `GET` | `/api/v1/mosques/bounds` | ম্যাপ ভিউপোর্টের বাউন্ডিং বক্স ডাটা | No |
| `GET` | `/api/v1/mosques/stats` | মোট মসজিদ ও মহিলাদের ব্যবস্থার পরিসংখ্যান | No |
| `PATCH`| `/api/v1/mosques/:id` | মসজিদের তথ্য / মহিলাদের ব্যবস্থা আপডেট | **Yes** |
| `POST` | `/api/v1/mosques/import` | নতুন CSV আপলোড ও বাল্ক ডাটাবেস এন্ট্রি | **Yes** |
